# GitHub Copilot CLI and VS Code compatible agent harnesses

Copilot CLI: copilot plugin install <extracted-plugin-directory>; start a fresh session. VS Code: run Chat: Install Plugin from Source in the Command Palette and select the extracted plugin directory, or use Agent Customizations -> Plugins -> add (+) -> local path. This standard package places *.agent.md under com.github.copilot/agents/. Existing Copilot access, a compatible selected harness and organisation policy apply.

The native host discovers the bundled skill and specialist definitions. Resolve the actual registered profile IDs from the host's available-agent list: some hosts namespace plugin profiles. Match the seven slm-mimir-<role> names, and use native dispatch sequentially. On OpenAI, use seven distinct native delegated agents and supply the seven role contracts. Never replace missing agents with role-play or a single model pretending to review itself.

The coordinator supplies absolute installed skill/workflow paths, exact requirements, candidate and prior handoffs. Pass these to each specialist; do not infer paths from the customer project's working directory. Keep source/evidence in the authorised customer workspace, never write inside the installed plugin. Inherit model, tools and permission boundaries. No Mimir account, API key, subscription or invitation. Node.js 20+ and file/command access are prerequisites.

One normal pass: seven passing stages completes the task. Only a genuine blocking finding requires repair. Optional suggestions do not force a second pass. Do not inject artificial defects, launch demonstrations, or run on ordinary conversation.

Documentation and package validation are not live model execution. Live Mimir runs on these providers have not been performed for this build, as instructed by the owner.
