# SLM Mimir — public free beta

**Version 0.2.0-beta.5-obfuscated.1 · Build 5**

SLM Mimir coordinates seven genuine specialists inside a capable AI interface:
Engineering → Mathematics → Auditor → Red Team → Optimiser → Verification → Strategist.

One normal run passes through those seven stages. If all pass, the task is complete.
Only a real blocking finding requires repair. No artificial defects, compulsory
repair exercises or demonstrations are included in normal operation.

These are provider-native integration packages prepared from official documentation,
with differing validation levels recorded in [PROVIDER_SUPPORT.txt](PROVIDER_SUPPORT.txt).
They are not a claim that every listed account/model configuration has been live-tested.
The owner instructed that Build 5 must not run Mimir/model tasks on target services.

**Chat modes differ:** OpenAI documents full native subagents in Work and Codex.
Anthropic documents plugin subagents in Cowork/Code, not ordinary Claude Chat.
Installing a plugin in ordinary chat does not create a capability the provider
does not expose. The coordinator must report a missing capability rather than
simulate seven independent agents. Read the exact interface entry before use.

The registry is extensible. There is no Mimir model allowlist: agents follow
the host's selected model/routing and existing permissions. Additional capable
interfaces can receive their own native format. Unconfirmed interfaces are
recorded openly rather than silently excluded or advertised as supported.

## Install and use

Download the ZIP for your interface, extract it when its installer requires a
folder, and follow **START_HERE.txt**. The package supplies all seven roles;
there is no manual creation of seven agents. Use the provider's normal plugin
or Skill installation controls. Native CLI instructions are for a normal local
terminal on your computer, not an SSH server.

Use an existing authenticated host account, genuine separate-agent tools,
authorised project/evidence storage and **Node.js 20+** for the helper. The
host itself may have additional installation requirements. Organisation,
account and platform restrictions apply. Do not lower host permission controls.

In a fresh supported session ask: **“Use SLM Mimir to build …”** or
**“Use SLM Mimir to audit …”**. Keep the model you selected in your host.

## Versions, downloads and feedback

Every package contains its version and build identity. [RELEASE.json](RELEASE.json)
lists the artifacts; [SHA256SUMS](SHA256SUMS) contains release checksums generated
during assembly. Final assembly did not perform further tests or validation runs.
Do not treat archive creation as live model verification.

For feedback include build number, exact interface/model, expected/actual
behaviour, failed stage and a minimal redacted example. Do not post passwords,
secret keys or private customer material. Disable/remove with the host's normal
controls; project files and saved evidence remain yours.

This repository supplies downloads and protected native plugin packages. Uploading it
to Hugging Face does not deploy or host the agents as a remote service.
